# Messhall feature map

Every surface a user or agent can reach, how to reach it, what it does, where it lives, and how to verify it. Source of truth for product scope is the plan in the local `personal-dev-notes.md`; this file is the operational index. Status is one of `planned`, `building`, `built`, `cut`. Update the row in the same commit that changes the surface, then run `pnpm messhall-dev featuremap --check`.

Contents: CLI, Dev tool, MCP server, Daemon, Feed, Mac app, Infra. Cells never hold a pipe character, since the parser splits on it.

## MCP server

Served by the daemon over Streamable HTTP at `http://127.0.0.1:7707/mcp`. Tool registration in `src/mcp/`, one file per tool under `src/mcp/tools/`, no business logic there. Inputs are zod contracts in `contracts/mcp.ts`. Tools never throw: they return `isError` text with the next step, and results are text only.

| Feature | Reach | Does | Code | Status | Verify |

| MCP endpoint | `POST`, `GET`, `DELETE /mcp` with `X-Messhall-Key` (agent key) | One `NodeStreamableHTTPServerTransport` and one `McpServer` per `Mcp-Session-Id`, behind the guard, the agent key and the SDK's localhost Host and Origin checks. Speaks `2025-11-25` and `2025-06-18` (echoes either when asked, answers `2025-11-25` to anything else, never `2026-07-28`) and declares `experimental['claude/channel']`. A sessionless non-initialize POST is 400, an unknown session 404. A session ends on DELETE, on transport close, or after 30 minutes with no open request, and its members turn gone. `sessionsFor({ room, name })` maps a member to its live session for the doorbell | `src/mcp/transport.ts`, `src/mcp/session.ts`, `src/daemon/server.ts` | built | `pnpm messhall-dev daemon --keep`, then `pnpm messhall-dev agent web --room demo --wait` |
